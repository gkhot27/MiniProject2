# Reflection: rwth-i6_returnn

RETURNN is my biggest project (12,000+ commits, around 160 authors) and the only one that never went inactive. It has 0 gaps of 3+ months, so I put "N/A active project" for the gap reason.

The longest zero-commit stretch is just 2 months (2014-07 to 2014-08), back when it was still an internal tool. The commits right after it say things like "towards open source release", so it was just early development.

I called the pattern steady, since it has had roughly 700-1,700 commits every year since 2015. I think it stays this consistent because a research group at RWTH Aachen uses it every day, with Albert Zeyer as the main contributor. It's clearly Active as of 2025-09-30, and recent commits are new PyTorch features and bug fixes.
