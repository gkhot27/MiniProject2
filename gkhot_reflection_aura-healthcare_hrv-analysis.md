# Reflection: aura-healthcare_hrv-analysis

Most of this project's commits happened in 2018, then it basically stopped, so I called it declining. It has 4 gaps of 3+ months, and the longest one is 40 months (2021-05 to 2024-08).

The gap was easy to explain. Right before it, the commits are about a JORS paper submission and a PyPI release, so it seems like the package was "done" once the paper was out. During the gap, users kept reporting that the package crashed because newer astropy moved LombScargle (#41, #42, #43), and even a fix PR (#40) was never merged.

It came back in September 2024 when Alexis Comte fixed that exact bug (#44) and Laura Dumont updated the CI. Both were new people from the Aura-healthcare org, not the original author. The revival didn't last though: the last commit before the cutoff was November 2024, so it's Inactive as of 2025-09-30.
