# Reflection: ipeagit_geobr

geobr had a massive first year (over 3,600 commits in 2019) and then settled into much lower but stable activity. I called it declining because of that drop. It only has 1 gap of 3+ months, which is also the longest: 2022-09 to 2022-12 (4 months).

This gap was easy to explain and not really a problem. It starts right after the v1.7.0 release in August 2022 and ends in late January 2023, so it covers the holidays. I didn't see anything worrying in the issues. Also, a lot of the commits around the gap are just GitHub Actions bot commits building the website.

Rafael Pereira, the main developer, came back in January 2023 and added a new function, read_capitals(). Since it was the same person, I don't think anything outside caused the gap. The repo has since moved to ipea/geobr and is Active as of 2025-09-30.
